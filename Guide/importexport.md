## 0. 60-second orientation

- **One interface per direction.** Every importer implements `mu::project::INotationReader::read(MasterScore*, path, Options)`; every exporter implements `INotationWriter::write(INotationPtr, IODevice&, Options)`. Both are *registered by file suffix* into two global registers owned by the `project` module. There is **no `IProjectRW`** in this tree (grep of `src\` finds nothing) — the registers are `INotationReadersRegister` / `INotationWritersRegister`.
- **Selection = lowercase suffix.** `project\internal\notationproject.cpp:131` — if `!isMuseScoreFile(suffix)` the project loader calls `doImport()`, which does `readers()->reader(suffix)` (`notationproject.cpp:292`). Export mirrors it: `writers()->writer(suffix)` (`notationproject.cpp:1017`, `exportprojectscenario.cpp:118`, `convertercontroller.cpp:222`). `io::suffix()` lowercases (`muse\framework\global\io\path.cpp:133`), so `.MXL` works.
- **Each format is its own module** (`iex_<name>`), built under `MUE_BUILD_IMPEXP_*_MODULE` options (`CMakeLists.txt:107-122`), registering itself in `resolveImports()`. Five formats (mei, midi, mnx, musicxml, ove) fall back to a **config-only stub module** when OFF (`src\importexport\CMakeLists.txt:42-72`, `src\stubs\importexport\*`); the others are simply not compiled.
- The 3 files that matter most: `src\project\inotationreader.h`, `src\project\inotationwriter.h`, `src\project\internal\exportprojectscenario.cpp`. For MusicXML: `internal\import\importmusicxml.cpp` + `…pass1.cpp` + `…pass2.cpp` + `internal\export\exportmusicxml.cpp`. For MIDI: `internal\midiimport\importmidi.cpp` + `internal\midiexport\exportmidi.cpp`.

## 1. The reader/writer framework

### 1.1 Interfaces (`src\project\`)

```cpp
// inotationreader.h:37-49 — INotationReader
enum class OptionKey { ForceMode /* Ignore lower priority errors (like version errors) */ };
virtual muse::Ret read(MasterScore* score, const muse::io::path_t& path, const Options& options = Options()) = 0;
```

```cpp
// inotationwriter.h:34-70 — INotationWriter
enum class UnitType { PER_PAGE, PER_PART, MULTI_PART };
enum class OptionKey { UNIT_TYPE, PAGE_NUMBER, TRANSPARENT_BACKGROUND, BEATS_COLORS, WAIT_FOR_COMPLETION,
                       WITH_AUDIO, LEADING_SILENCE_SEC, TRAILING_SILENCE_SEC };
virtual std::vector<UnitType> supportedUnitTypes() const = 0;
virtual bool supportsUnitType(UnitType) const = 0;
virtual muse::Ret write(INotationPtr, IODevice&, const Options& = Options()) = 0;          // one score
virtual muse::Ret writeList(const INotationPtrList&, IODevice&, const Options& = Options()) = 0;  // MULTI_PART
virtual muse::Progress* progress() { return nullptr; }   // writers that are slow/async override
virtual void abort() {}
```

- **Reader contract:** it receives a *fresh, empty* `MasterScore` — style, chord list and engraving-project setup are done by the caller, not the reader (§1.3). It returns a `Ret` built with `engraving::make_ret(Err, path)` (error codes in `engraving\engravingerrors.h`).
- **UnitType semantics** drive the export loop: `PER_PAGE` = one file per page (PNG, SVG), `PER_PART` = one file per notation (score or part), `MULTI_PART` = one file containing several notations (PDF only).
- **`write()` vs file path:** writers stream to an `IODevice`; two writers (video, and the aac sub-writer it spawns) need the real path and read it from `device.meta("file_path")` (`videowriter.cpp:103`; set at `exportprojectscenario.cpp:438`, `convertercontroller.cpp:84` comment).

- Registered as global-IoC exports in `project\projectmodule.cpp:79-80` (`registerExport<INotationReadersRegister>` / `<INotationWritersRegister>`).
- Interface comment (`inotationreadersregister.h:39`): "In the future, we need to replace the suffix with an enumerator or a better structure describing the format." — suffix is the whole key; **content sniffing is not done by the registry** (only individual readers sniff, e.g. Guitar Pro, §6).
- Each importexport module wires itself in `resolveImports()` (runs after all `registerExports()`), e.g. `musicxmlmodule.cpp:52-67`: resolve the register from `globalIoc()`, `reg({...suffixes}, make_shared<Reader>())`. Because registration is `if (readers)`-guarded, a missing project module degrades silently.
- **Writers outside importexport** register into the same writer register: `notation\notationmodule.cpp:65-68` → `spos`, `mpos` (positions writers), `mscz` (Zip), `mscx` (Dir); `braille\braillemodule.cpp:59` → `brf`.

### 1.3 Import flow (`NotationProject::doImport`, `notationproject.cpp:286-352`)

1. `load()` (`:120`): `format = io::suffix(path)`; non-MuseScore suffix ⇒ `doImport`.
2. `readers()->reader(suffix)`; null ⇒ `Err::FileUnknownType`.
3. `OpenParams.forceMode` → `options[ForceMode]` (only honored by MusicXML and MEI — see §4/§6; MIDI, GP, etc. ignore `Options`).
4. Optional style: `stylePath` (open params, else `notationConfiguration()->styleFileImportPath()`) is loaded via `EditStyle::loadStyle` *before* the reader runs (`:311-317`). Comment at `:308`: "The order of the steps matches the order in MS3".
5. `score->checkChordList()`, then **`scoreReader->read(score, path, options)`**.
6. `m_engravingProject->setupMasterScore(forceMode)`, optional `unrollRepeats` (`:334`), audio settings + view state `makeDefault()`.
7. Result: `listenIfNeedSaveChanges()` — an imported project has no `.mscz` path; saving later asks for a new file.

`OpenProjectScenario::isFileSupported` (`openprojectscenario.cpp:220-232`) = `isMuseScoreFile(suffix) || readers()->reader(suffix)`. The Open dialog filter list is **hard-coded separately** (`openprojectscenario.cpp:903-924`) — adding a reader does not add it to the file-picker.

### 1.4 Export flow (`ExportProjectScenario`, `project\internal\exportprojectscenario.cpp`)

- Export types shown in the dialog are **hard-coded** in `ExportDialogModel` ctor (`project\qml\MuseScore\Project\internal\Export\exportdialogmodel.cpp:53-131`): pdf, png, svg, mp3, wav, ogg, flac, aac, mp4 (`#ifdef MUE_BUILD_IMPEXP_VIDEOEXPORT_MODULE`), mid/midi/kar, MusicXML (subtypes mxl/musicxml/xml), brf, mei, mnx, lrc. Each carries a QML settings page name. `ExportType::makeWithSuffixes` (`exporttype.cpp:91`) takes `id = suffixes.front()`.
- `exportScores()` (`:114-261`): looks up writer by destination suffix; asserts `supportsUnitType`; inits any not-yet-created excerpts (`:146`); **force-lays-out** scores that have autolayout off (`:149-154`); switches every notation to `ViewMode::PAGE` for the duration and restores in a `DEFER` (`:157-187`); wires the writer's `progress()` to a modal progress and `abort()` to its Cancel (`:160-176`); then loops by UnitType:
  - `PER_PAGE`: per notation, per page, `options[PAGE_NUMBER]=page`, path suffixed `-<page+1>` (`completeExportPath`, `:342-358`);
  - `PER_PART`: one `write()` per notation;
  - `MULTI_PART`: one `writeList()` to one file.
- `doExportLoop` (`:410-481`) deletes any existing file first, opens a `FileStream` WriteOnly, calls the lambda, and implements Replace/Skip/Retry prompts (`:360-408`). On a `Cancel` it removes the partial file with up to 10×100 ms retries (Windows lock workaround, `:457-467`).
- Batch/CLI path: `converter\internal\convertercontroller.cpp:220-324` — same register lookup (`:222`), `mscz/mscx/mscs` short-circuit to project save (`:298-306`), `png/svg` are page-by-page (`isConvertPageByPage`, `:503-511`), everything else `convertFullNotation`. See `mscore-cli.md`.

### 4.2 Import pipeline

`MusicXmlReader::read` (`musicxmlreader.cpp:31-46`): reads `ForceMode` option, then by suffix → `importMusicXml(score, path, forceMode)` (`xml`/`musicxml`) or `importCompressedMusicXml` (`mxl`); any other suffix leaves `Err::FileUnknownType`.

```cpp
// importmusicxml.cpp:221-270
Err importMusicXml(MasterScore*, const String& name, bool forceMode)     // ScoreLoad sl; reads whole file → doValidateAndImport
Err importCompressedMusicXml(MasterScore*, ...)                          // extractRootfile(): ZipReader, META-INF/container.xml → rootfile@full-path
static Err doValidateAndImport(Score*, name, data, forceMode)            // if (!forceMode) validate(); then importMusicXmlfromBuffer
```

`importMusicXmlfromBuffer` (`importmusicxml.cpp:89-128`) — **two-pass design**:

1. `MusicXmlParserPass1 pass1(score, &logger); pass1.parse(data)` (`importmusicxmlpass1.cpp:1289`) — scan the whole file, create nothing but structure: collects part list, divisions, per-part measure lengths, voice/staff mapping, credits, page layout, instruments; then `determineMeasureLength`, `determineMeasureStart`, `fixupSigmap`, and **`createMeasuresAndVboxes`** (`:1299-1306`) builds the empty measures + title VBox/credit frames in the score.
2. `MusicXmlParserPass2 pass2(score, pass1, &logger); pass2.parse(data)` (`importmusicxmlpass2.cpp:2114`) — re-read and create the actual content (chords, rests, notes, beams, tuplets, spanners, lyrics, harmony, figured bass, barlines…) into those measures.
3. After both: `Instrument::updateInstrumentId()` for every part instrument (`:107-111`). If either pass accumulated errors **and** `!MScore::noGui`, the user gets a Yes/No "Do you want to try to load this file anyway?" dialog (`:115-125`, text built at `:62-81`); No ⇒ `Err::UserAbort`. In CLI/noGui the errors are silently tolerated.

Both passes accept only `score-partwise`; any other root (including `score-timewise`) returns `Err::FileBadFormat` (`pass1.cpp:1319-1345`, `pass2.cpp:2131-2151`). ⭐ **Timewise MusicXML is not supported.**

Pass 1 key structures (`importmusicxmlpass1.h`): `PageFormat`, `MusicXmlPartGroup` (bracket/brace spans), `CreditWords`, `MusicXmlOctaveShiftDesc`; parse methods `scorePartwise/identification/credit/defaults/partList/partGroup/scorePart/scoreInstrument/midiInstrument/part/measure/print/attributes/clef/time/transpose/divisions/direction/note/forward/backup/timeModification/pitch/rest`. `scorePartwise()` (`pass1.cpp:1394`) fills metadata tags (`workNumber/workTitle/movementNumber/movementTitle`), then adds explicit brackets/braces from `part-group` and implicit braces for multi-staff parts. `m_maxDiff = 5` ticks is the duration-rounding tolerance (`pass1.h:248`); `m_adjustedDurations`/`m_seenDenominators` track rounding.

**Exporter-software detection** (`pass1.cpp:411-436`): `setExporterSoftware` reads the `<encoding><software>` string and sets `MusicXmlExporterSoftware` ∈ {SIBELIUS, DOLET6, DOLET8, DORICO, FINALE, NOTEFLIGHT, OTHER}; this enables per-exporter workarounds in both passes (e.g. `sibOrDolet()` → `Sid::fretFrets=5`; Finale-specific text handling at `pass1.cpp:1486, 2543`).

Pass 2 (`importmusicxmlpass2.h`): classes `MusicXmlParserPass2`, `MusicXmlParserNotations` (the `<notations>` subtree: arpeggio, articulations, dynamics, fermata, glissando/slide, ornaments, slur, technical, tied, tuplet…), `MusicXmlParserLyric`, helpers `SlurDesc`, `MusicXmlSpannerDesc`, `MusicXmlExtendedSpannerDesc`, `MusicXmlLyricsExtend`, `HarmonyDesc`, `InferredPercInstr`, `DelayedArpeggio`. `scorePartwise()` (`pass2.cpp:2207`) loops `part` / `part-list`, normalizes the last-measure barline (comment `:2218-2220`), then **adds queued system-level elements via `undoAddElement`** and removes duplicated text/text-line system elements (`:2231-2240`). Supporting files: `musicxmlpart.*` (per-part data: instruments, vocal/percussion flags), `musicxmltupletstate.*`, `musicxmlvoicedesc.*` (voice↔track allocation), `importmusicxmlnoteduration.*`, `importmusicxmlnotepitch.*`, `importmusicxmllogger.*` (levels ERROR/INFO/TRACE; importer fixes it at ERROR, `importmusicxml.cpp:92`).

### 4.3 Export pipeline

`MusicXmlWriter::write` (`musicxmlwriter.cpp:49-62`): resolves `Score*` from `notation->elements()->msScore()` and calls `saveXml(score, &device)`; **`Options` are ignored**; only `PER_PART` is supported (`:38-41`); `writeList` = NOT_SUPPORTED. `MxlWriter::write` → `saveMxl`.

- ⭐ `writeParts()` (`:8819-8884`) iterates `m_score->pages() → page->systems() → system->measures()`, i.e. it **walks the laid-out page/system structure** (needed for `<print new-system/new-page>`). - `writeMeasure` (tail at `:8660-8747`) emits, in order: `divisions` (first measure), key/time (`keysigTimesig`), `staves`/`instruments`, clefs (`findAndExportClef`/`exportDefaultClef`), `staff-details`, instrument details, `measure-style`, repeats (only part 0: "MuseScore limitation: repeats are always in the first part", `:8709`), per-staff content (`writeMeasureStaves`), unattached annotations, trailing tick move, right barline.

Measure-end processing (`:3042-3126`): leftover grace chords become grace-after of the previous chord; tuplets reset (cannot cross barlines); `fillGapsInFirstVoices`; open beams removed; inferred fingerings and delayed directions are **sorted by `abs(totalY())`** (so printed order roughly follows `default-y`) and added via `addElemOffset`; `measure->setTimesig(m_timeSigDura)`; `markUserAccidentals` converts superfluous accidentals to user accidentals using `alterMap`; multi-measure rest count (`getAndDecMultiMeasureRestCount()==0` -> `setBreakMultiMeasureRest(true)`); `setMeasureRepeats` (`:3136`) places a `MeasureRepeat` in the *center* measure of an odd-length group. It also **clears** `repeatStart/repeatEnd` first (single-measure repeats and unordered repeat barlines, `:2864-2866`).

**`note()` (`:7069-7599`) — the core algorithm.**
1. `print-spacing="no"` -> treated like `forward` (`notePrintSpacingNo`) and returns null.
2. Child loop: `MusicXmlNotePitch mnp` and `MusicXmlNoteDuration mnd` helper classes `readProperties()` first (pitch/unpitched/display-step; duration/dots/time-modification/type), then `beam` (collects beam types per level into `beamTypes`), `chord`, `cue`, `grace` (`slash`, `steal-time-previous/following`), `instrument`, `lyric`, `notations`, `notehead` (`none` -> `hasHead=false`; Noteflight `named` -> `HEAD_PITCHNAME`), `notehead-text` (one char -> pitch-name scheme, German if `H`/ altered `B`; multi-char -> solfege fixed/movable), `rest`, `staff`, `stem`, `tie`, `type` (`size=cue|grace-cue` => small), `voice`. Attribute `dynamics` becomes `note->setUserVelocity(clamp(round(dynamics*0.9),1,127))` (0 = silent note stored as 1, `:7110-7114`).
3. **Sibelius 7.1.3 workaround**: a `<chord/>` note without `<voice>` inherits the last non-chord voice (`:7225-7232`).
4. `mnd.checkTiming(type, rest, grace)` may repair duration vs type; then voice mapping via `determineStaffMoveVoice` (above).
5. `noteStartTime = chord ? prevSTime : sTime`. For non-chord, non-grace notes the tuplet state machine runs **before** allocation (to stop a previous tuplet and add missing rests, `:7283-7305`) and **after** (to start/add/stop, `:7513-7548`).
6. Allocation: rest -> `addRest`; note -> `findOrCreateChord` (adds to an existing chord at that tick/track, "ignores `<chord/>` errors"); grace -> `createGraceChord` collected in `gcl` (`<chord/>` on a grace joins `gcl.back()`). Pitch via `setPitch` (octave-shift from pass-1 `octaveShift()`; unpitched single-drumset parts use `xmlSetDrumsetPitch`, `:6989`), or `setDrumset` for multi-instrument percussion.
7. Decorations: head group/scheme, colors (`colorItem`), parentheses, visibility from `print-object` (`hasHead && printObject`), `setPlay(!cue)` (cue notes do not play), `handleBeamAndStemDir` (only for the first note of a chord), grace-before/after attachment (`addGraceChordsBefore/After`), accidentals (`mnp.acc()` else `accType`), `setNoStem`.
8. If `calculatedDuration != specifiedDuration` (pass-1 duration differs from the notated `type`), a **play-event length** in 1/1000ths is stored (`NoteEvent.setLen`, `PlayEventType::User`, `:7430-7447`) so playback honours the real MusicXML duration.
9. `notations.addToScore(...)` (`:9601`) adds slurs/ties/glissandi/spanners/trills/arpeggios; if no tie exists but a `<tie>` was seen, it is converted into a synthetic `tied` Notation (`:7490-7496`). Two-note tremolo is handled *before* tuplet logic because it changes `timeMod`. Lyrics: grace-note lyrics are deferred to the main chord (`m_graceNoteLyrics`); rests stop all lyric extends; figured bass added via `addFiguredBassElements`.
10. Returns the `Note*`; `dura` is zeroed for chord/grace notes (`:7592-7594`).

**Tuplet state machine (`MusicXmlTupletState`, `musicxmltupletstate.cpp`).** One per voice. `determineTupletAction()` returns a flag set `{NONE, START_NEW, ADD_CHORD, STOP_CURRENT, STOP_PREVIOUS}` from the note duration, `time-modification` (`actualNotes = timeMod.denominator()`, `normalNotes = numerator()`), `<tuplet type=start|stop>`, and `<normal-type>`:
- unexpected end of previous tuplet (`inTuplet && timeMod==1/1`) or a second `start` while in one => STOP_PREVIOUS, and if not filled `missingPreviousDuration = missingTupletDuration(duration)` (the importer inserts a filler rest in the old tuplet, `pass2.cpp:7289-7304`);
- START_NEW when `<tuplet start>` or (no tuplet open and timeMod != 1:1); `implicit=true` for the latter;
- ADD_CHORD whenever in a tuplet and timeMod != 1:1 (running `smallestNoteType/Count` bookkeeping: dotted = next-smaller type x3, double dotted x7, `smallestTypeAndCount`/`matchTypeAndCount`);
- STOP_CURRENT on `<tuplet stop>`, or (implicit tuplet and `isTupletFilled`), or timeMod back to 1:1; if `actNotes > norNotes` and not filled, `missingCurrentDuration` is padded with a rest.
`isTupletFilled`: with `<normal-type>` compares smallest-note count against `actualNotes` at that type; otherwise `smallestNoteCount >= actualNotes`. `determineTupletFractionAndFullDuration` splits a duration into (fraction in (1/2,1], power-of-2 fullDuration) for filler computation (examples in the comment at `:66-80`). Nested tuplets are an explicit TODO. 

**Barlines (`barline()`, `:5845-5995`).** `location` right/left/middle selects the tick (`measure->endTick()`/`tick()`/current). Children: `bar-style`, `segno`/`coda` (Marker placed on the *next* measure for right-located marks; error "cannot be placed at the end of the score"), `fermata` (on BarLine/EndBarLine/BeginBarLine segment; also **terminates inferred tempo lines**), `ending` (-> `doEnding`, volta), `repeat` (`times` default 2 -> `setRepeatCount`; `winged` toggles style `Sid::repeatBarTips` globally). `determineBarLineType(barStyle, repeat, ...)` maps style+repeat to `BarLineType`; START/END repeat set `measure->setRepeatStart/End`; other non-regular barlines become real `BarLine` elements on the first voice of every staff of the part, spanning all but the last staff.

**Directions (`MusicXmlParserDirection::direction`, `:3546-`).** Collects `direction-type` children (words, rehearsal, metronome, dynamics, wedge, bracket/dashes, octave-shift, pedal, segno/coda, harp-pedals, other-direction), `offset` (divisions -> ticks), `sound`, `staff`. Spanner start/stops are put in `starts/stops` lists and applied after the loop (staff is read *after* direction-type in file order, `:3571-3575`). Then classifies the collected text by a cascade of heuristics (several gated by `inferTextType`): `handleRepeats` (D.C./D.S./Fine/To Coda...), `handleNmiCmi`, `handleFraction`, `handleChordSym`, `handleDrumInstrument`; Sibelius 7.1.3 metronomes without `<sound tempo>` use the metronome-derived BPM; then in order: lyric bracket (dropped), likely composer/credit text -> `addTextToHeader(COMPOSER)`, likely subtitle -> SUBTITLE (also sets `source` tag), legal "downloaded" text (dropped), likely tempo text -> `TempoText` (`setTempo(bpm/60)`, `followText` if text contains `=`), likely tempo line -> `GradualTempoChange` start, likely sticking, dynamic range, else `Expression` (italic, below) / `SystemText` (`system="only-top"`) / `PlayTechAnnotation` / `StaffText` / `RehearsalMark` (bold explicitly turned off). Frame/align/placement applied only when `importLayout`.

**Lyrics (`MusicXmlParserLyric::parse`, `:8286-8384`).** `syllabic` -> `LyricsSyllabic`; `elision` concatenated into formatted text; `extend` recorded; lyric number via per-part `LyricNumberHandler::getLyricNo` (errors: `<0`, `>MAX_LYRICS`, duplicate); `relative-x/-y` and `default-y` are tenths -> `*0.1*DPMM`; with `inferTextType` and a non-vocal staff, a single-syllable text matching `^[lrbLRB]+$` becomes a `Sticking` instead of `Lyrics` (`isLikelySticking`, `:8395`). A lyric with `extend` (type empty/start) on SINGLE/END syllable is registered in `m_extendedLyrics`.

**Slurs (`addSlur`, `:8436-8552`).** Per-part `SlurStack` indexed by `number-1`. start-after-start = "ignoring duplicate slur start" (PriMus/Sibelius workaround); stop-before-start *parks* a stopped `SlurDesc` and the later start completes it; a slur that starts and ends on the same chord becomes a **`LaissezVib` tie** instead; `slur` with end before start is deleted with an error. `line-type` dashed/dotted -> `SlurStyleType`; orientation/placement honoured only when `importLayout`. The same code builds `HammerOnPullOff` when the notation name is not `slur`. `tied` notations are inserted at the **front** so "stops" are processed before "starts" (`tied()`, `:8562-8578`).

**Exporter internals (`export\exportmusicxml.cpp`).**
- `calcDivisions` (`:1239-1318`): walks every part/measure/track/segment, accumulating **every ChordRest duration (x stretch) and every backup/forward gap** into a fraction set; `divisions = lcm(4, all denominators) / 4`. Two-note tremolo durations are halved; START_REPEAT barlines skipped; figured-bass durations included.
- Measure content order is track-by-track, **not** segment-by-segment: `writeMeasureTracks` (`:8430-8542`) loops `track` in a staff and `segment` inside it, calls `moveToTickIfNeed` (emits `<backup>`/`<forward>`), instrument change (first track only), then for ChordRests: tbox text-as-words (above on first part / below on last staff of last part, once per measure), `harmonies`, `annotations`, `figuredBass`, `spannerStart`; then `writeElement`; then `spannerStop`. TimeTick segments (spanner anchors without a chord) start/stop spanners only if the staff has no real ChordRest at that tick.
- `writeElement` (`:7980-8032`): `Clef` — only *non-generated* mid-measure clefs and `after-barline="yes"` clefs at measure start; `Chord` — grace-before chords, the chord, grace-after chords, each via `chord()` (`:4349`) which shares the lyrics list; `Rest` (skipping gap rests); mid-measure `BarLine`; KeySig/TimeSig/Breath/TimeTickAnchor are handled elsewhere. MeasureRepeat measures re-walk the *source* measures (`writeMeasureStaves`, `:8577-8605`).
- `writeStaffDetails` (`:8055-8145`): emitted only when lines != 5, tab staff, mag != 1, hidden, or colored/invisible lines; includes `staff-type alternate` for linked tab staves, `staff-lines`, `line-detail`, `staff-tuning` (via `midipitch2xml`, octave clamped 0-9), `staff-size` (mag x lineDistance x 100).
- Tests reference the import side only through the harness in §4.5; each element's round-trip fixture lives in `musicxml\tests\data`.

### 8.2 MIDI import stage algorithms (TRACED: `MidiFile`, key, tempo, meter, quant core + DP, tuplet detect, L/R hand, voice sort, clef, swing, drum, human-performance/beat)

Dir: `midi\internal\midishared\midifile.cpp`, `midi\internal\midiimport\importmidi_*.cpp`. Pipeline order is in §5.2; below are the algorithms. Time unit throughout is `ReducedFraction` (ticks as a reduced fraction; `Constants::DIVISION` ticks per quarter).

**`MidiFile` parser (`midifile.cpp:196-635`).** `read()`: "MThd", header length must be exactly 6 (`>6` throws `QString`), `format` 0 or 1 (format 2 throws "not implemented"), division: top bit 0 = ticks per beat; top bit 1 = SMPTE (`isDivisionInTps`, `framesPerSecond*ticksPerFrame`, 29 fps -> `qRound(29.97*tpf)`). `readTrack`: "MTrk", **running status is kept in `sstatus` across meta/sysex** (`status=-1` only breaks the local one); a wrong track length logs a warning and skips forward but is not fatal. `readEvent`: delta via `getvl()`; unknown 0xF1-0xFE bytes skipped; sysex (0xF0/0xF7) -> `ME_SYSEX` (warns when not 0xF7-terminated); meta -> `ME_META` with `metaType` + data; channel events: polyphonic aftertouch -> controller `CTRL_POLYAFTER` (value=(a<<8)|b), channel aftertouch -> controller `CTRL_PRESS`; a set high bit in a data byte is an error unless it was `b` (then it is reinterpreted as a new status byte "try to fix").
`MidiTrack::mergeNoteOnOff` (`:655-818`): pairs each NOTEON with the next NOTEOFF / vel-0 NOTEON **of the same pitch** (searching forward over *all* channels in that track) into one `ME_NOTE` with `len = off - on` (min 1; no off found -> len 1, "-no note-off"); stray offs are dropped. It also **folds controllers**: bank MSB/LSB + program -> `value=(hbank<<16)|(lbank<<8)|prog`; RPN/NRPN (CC 98-101 + data entry 6/38) -> synthetic controller `dataType|(rpnh<<8)|rpnl` (0x20000 RPN, 0x30000 NRPN; 14-bit when a data-LSB follows); a Yamaha sysex "part mode" (`43 1n 4c 08 xx 07 mm`) with mm != 0 marks the track as drums. `MidiFile::separateChannel` (`:826-873`) splits any track containing events for several channels into one track per channel (sorted channel order) and `setOutChannel`; **channel 9 => `_drumTrack = true`** (`setOutChannel`, `:641-647`).

**Key detection (`importmidi_key.cpp:38-193`, Kilian 2004).** `findKey` counts, over all non-drum tracks, adjacent-chord note pairs a semitone apart: `counts[min(p1,p2) % 12]++`. Each of the 15 keys scores the sum of the two semitone-transition counts that *define* its leading-tone pairs (e.g. C = counts[4]+counts[11] (E-F, B-C); G = counts[11]+counts[6]); sort descending by score, ties broken by smaller `|accidentals|` (`KeyData::operator<`). Runs only if human-performance or any track lacks a key event (`recognizeMainKeySig`); for transposing instruments it sets the concert key and, unless concert-pitch is on, a flipped-interval transposed written key (`Transpose::transposeKey`). Keys are assigned via `assignKeyListToStaff` (skips redundant C).

**Tempo (`importmidi_tempo.cpp`).** `findBasicTempo`: first `META_TEMPO` found (3-byte µs/quarter -> beats/sec = 1e6/µs; default 2 = 120 bpm); for human performances the tempo-only (chord-less) track is skipped as unreliable. `applyAllTempoEvents`: gathers `(tick -> bps)` then applies in tick order (comment: tempo-only tracks share one map key, so direct iteration is *not* tick-ordered); SMPTE division files get a single tempo at tick 0. `setTempoToScore`: skips if a TempoText already exists there, skips repeats of the same tempo (except tick 0), hides tick-0 default 120 unless `showTempoText`; text is `<sym>metNoteQuarterUp</sym> = N` (N rounded when `roundTempo`); tempo texts are always created (visible only if `showTempoText`). Human performance with a detected beat set instead emits **one** tempo: `basicTempo * averageTempoFactor` where factor = mean(`DIVISION / beat interval`).

**Human-performance detection (`importmidi_quant.cpp:399-482`).** All tracks' chords are merged (`getTrackWithAllChords` + `collectChords`); for each chord quantize on-time to `min(1/16, quantForLen(maxNoteLen))` and, if the quantized on-time falls on a beat, count it; a match is `|quantized - actual| < minAllowedDuration`. If `matches/count < 0.6` => human. Human => default `quantValue=Q_8`, `maxVoiceCount=V_2`, then `MidiBeat::findBeatLocations`. Defaults are only set if `canRedefineDefaultLater()` (i.e. the user has not overridden them in the operations file).

**Beat tracking & time signature (`importmidi_beat.cpp`).** For two salience functions (`findChordSalience1/2`) the chords become beatroot `Event`s; `BeatTracker::beatTrack` yields beat times; if `<= 8` beats the function is skipped. Candidate time signatures are `{4/4, 3/4}` unless the file has another, in which case **only the file's** (`findTimeSignatures`). For each candidate, `findMatchRank` scores how well beat-salience ordering agrees with the metric levels of that meter (fraction of beat pairs whose salience order matches `levels[i]<levels[j]`, averaged over bars); the best-ranked (`std::greater` map) wins: sigmap is cleared and set to that single signature, `humanBeatData` stored and the UI-facing defaults `measureCount2xLess/timeSigNumerator/Denominator` updated. `removeEvery2ndBeat` implements the "measureCount2xLess" option (halve the beat grid).

**Meter model (`importmidi_meter.cpp`).** Classifies the bar by numerator: simple (<5), compound (%3==0 && >3), complex (5 or 7), duple (2|6), triple (3|9), quadruple (%4), quintuple, septuple. `metricDivisionsOfBar` builds a list of (length, level) from the whole bar (level 0) downward: pulse division by meter class (quadruple adds a central half-bar accent), compound adds a /3 pulse subdivision, then halves until `< 2*minAllowedDuration`. `metricDivisionsOfTuplet` appends tuplet divisions with `TUPLET_BOUNDARY_LEVEL`. `levelOfTick(tick, divsInfo)` returns the *first* division whose grid contains the tick (tuplets first, bar last). `divisionsOfBarForTuplets` limits tuplet search to beat level and below for compound/complex meters. `beatLength`: /2 duple, /3 triple, /4 quadruple, /numerator complex, default /4.

**Quantization (`importmidi_quant.cpp`).**
- `quantValueToFraction`: Q_4=DIVISION ... Q_1024=DIVISION/256 (each step halves); default from `io/midi/shortestNote` (`defaultQuantValueFromPreferences`, invalid -> 16th).
- `quantizeChords` (`:1487-1516`): `applyTupletStaccato` -> `quantizeOnTimes` (per bar, per voice, per tuplet/non-tuplet *range*) -> `findQuantizedChords` -> `quantizeOffTimes` -> `removeUselessTupletReferences`.
- **On-time quantization is a dynamic program** over the chords in a range (`quantizeOnTimesInRange`, `:1161-`): `findQuantData` builds per chord a `QuantData` with `quant` (from the shortest note/gap via `quantForLen`, or the tuplet quant), `quantForLen`, `chordRangeStart/End` (grid points between `chord.on - beatLen` and `+ beatLen`, clipped by neighbours: ranges must be monotone and, unless `canMergeWithPrev`, disjoint), candidate `positions` on the quant grid each tagged with `metricalLevel`, and `metricalLevelForLen` (highest metric level reachable at the note-length grid). Cost (`applyDynamicProgramming`, `:1096-1159`): `timePenalty = |chord.on - p.time|`; **human**: `level <= levelForLen ? time + |Δlevel|*quantForLen : time/(1+|Δlevel|)`; **non-human**: `level <= levelForLen ? time*(1+|Δlevel|) : time`. Transition: previous position must be `<=` current; equal position allowed only if `canMergeWithPrev`, costing `+quant*5` (`MERGE_PENALTY_COEFF`). Optimal path recovered backwards (`findLastChordPosition` + `prevPos`), keeping the lower-penalty result if a chord is found by two ranges.
- `preserveLegato` (`:486`) trims small overlaps with the next chord; `moveOffTimes` (`:1406`) shifts off-times when quantizing pushed on-time past them (preserving original length).

**Tuplet detection (`importmidi_tuplet_detect.cpp`, limits in `importmidi_tuplet.cpp:39-50`).** Per bar, for every metric division length `divLen` (`divisionsOfBarForTuplets`) and each slot in the bar, `findTupletNumbers` selects candidates: compound meter at beat level -> 2-plets and 4-plets; otherwise 3,5,7,9-plets — each gated by the per-track `searchNplets` flags. For a candidate (guards: `isNextBarOwnershipOk` — at most one chord from the next bar and it must be the last; `isTupletLenAllowed` — tuplet note length >= regular quant for the range) `findTupletApproximation` assigns chords to tuplet positions: for each of the N slots every chord within +-half a tuplet-note is a candidate keyed by `(tupletError, tupletError - regularError)`; candidates are consumed best-first while the cumulative `tupletError - regularError` stays <= 0, one chord per slot and each chord once. Staccato (`detectStaccato`, only with `simplifyDurations` and no chord between tuplet slots) lets short notes be lengthened to the tuplet note length. `isTupletAllowed`: first-and-single duplet/triplet note must be about `len/N` long; chord count >= `minNoteCount` (or `minNoteCountHuman` for human); **duplets and quadruplets** need `tupletSumError <= regularSumError`, **all others strictly <**; and at least one note must be >= half a tuplet note. Limits table (`ratio`, `minNoteCount`, `minNoteCountAddVoice`, `minNoteCountStaccato`, `minNoteCountHuman`): 2:{2/3,1,2,2,2}, 3:{3/2,1,3,3,2}, 4:{4/3,3,4,3,3}, 5:{5/4,3,4,4,4}, 7:{7/8,4,6,5,6}, 9:{9/8,6,7,7,8}. Overlapping/conflicting candidates are resolved in `importmidi_tuplet_filter.cpp` (`filterTuplets` — picks the best set by total quant error with voice-count limits; `removeUselessTuplets`, `findBestTuplets`, `removeExtraTuplets`); `importmidi_tuplet_voice.cpp` allows a first chord shared by two tuplets in different voices; `importmidi_tuplet_tonotes.cpp` writes `Tuplet` elements when notes are created.

**Left/right-hand split (`importmidi_lrhand.cpp`).** Only for grand-staff programs (`MChord::isGrandStaffProgram`) with at least one chord spanning more than an octave (`needToSplit`). `findSplits` is a **dynamic program** over chords: per chord, for every split point `s` (notes sorted ascending; low part `[0,s)` = left hand, high part `[s,n)`; `s==n` means whole chord to the left hand) penalty = `pitchWidthPenalty` (0 if a hand spans <= 12 semitones, 20 up to 14, 100 beyond) + `durationPenalty` (-10 per hand with equal off-times) + `noteCountPenalty` (5 when LH has fewer notes than RH, 10 if RH empty and LH>1), plus the best previous-split transition: previous penalty + `similarityPenalty` (octave pairs -12, accompaniment -5, single-note melody -12) + `intersectionPenalty` (+10 per hand whose earlier notes still sound at the new on-time, scanning back `maxChordLen`). `splitChords` backtracks and creates a new left-hand `MTrack` inserted after the original (multimap equal-key ordering guarantee relied on, `:434-439`).

**Voice separation (`importmidi_voice.cpp`, 1123 lines; outline + `doVoiceSeparation`/`sortVoices`).** Applies per non-drum track if `userVoiceCount` in `(1, voiceLimit()]`. `doVoiceSeparation` (`:895-953`): sort notes in each chord by length; per chord `findOptimalSplitPoint` (minimizes resulting duration count using `findDurationCount`), `findPossibleVoiceSplits` (candidate target voices respecting `hasIntersectionWithTuplets`, max voice per bar via `maxOccupiedVoices`), `findBestSplit` (minimize pitch distance to neighbours then voice number), `splitChordToVoice` (+tuplet cloning/splitting, with the rule "parallel equal tuplets in different voices aren't pretty" so the old tuplet is erased when a new one is inserted). `sortVoices` then renumbers voices **per bar group by descending average pitch** (highest-pitched voice becomes voice 0), updating tuplet/note voice references.

**Clef (`importmidi_clef.cpp`).** Mid pitch 60: average pitch < 60 -> F else G for the main clef. Clef *changes* are a 2-state (treble/bass) dynamic program over chords with per-note penalty (`findPitchPenaltyForClef`: treble: 0 at >=60, 1 below 60, 10000 below 55, 20000 below 50; bass mirrored at 60/65/70) plus a change penalty (`findClefChangePenalty`: 1000 normally, 10001 if the previous chord was already a different clef, +2 "orphan chord" when a >= beat-long rest ends the lookaround, window `notesBetweenClefs=5`). Clefs are created from score start to end after DP. Piano G+F program staves use fixed G/F (`hasGFclefs`).

**Drums (`importmidi_drum.cpp`).** `splitDrumVoices`: for drumset pitches with `drumset->voice(pitch)==1` move notes to voice 1 (split chord if only some notes); `splitDrumTracks` (when `doStaffSplit`): one new MTrack **per percussion pitch**, named from the drumset, inserted in pitch order; `setStaffBracketForDrums` brackets runs of drum staves from the same operation index.

**Swing (`importmidi_swing.cpp`).** Per staff `SwingDetector` accumulates ChordRests on each quarter-note beat; at a full 1/4: `SWING` pattern = (triplet-quarter + triplet-eighth with a chord) or (8th chord, 8th rest, 8th chord) -> rewritten as two straight 8ths (second moved to `startTick + DIVISION/2`, tuplet deleted, rest removed); `SHUFFLE` = dotted-8th(3/16)+16th(1/16) non-tuplets. If anything changed, a staff text "Swing"/"Shuffle" is added at the first segment.

### 8.3 Guitar Pro internals (TRACED: GP1-5 helpers, GP5 beat/bar reading, GPX container, `GPConverter` driver, tempo map, setPitch, bend path)

**GP1-5 binary readers** (`guitarpro\internal\importgtp*.cpp`; class chain `GuitarPro` base -> `GuitarPro1..5`, each overriding `read`, `readNote`, `readBeatEffects`...). Base primitives (`importgtp.cpp:172-294`): `readInt` = little-endian 32-bit; `readPascalString(n)` = length byte + text padded to `n`; `readDelphiString` = int32 max-length + byte length (+ assert if they mismatch and `maxl>255`); `readWordPascalString`/`readBytePascalString`; UTF-8 if valid, else Latin-1 (`UtfCodec::isValidUtf8`). `len2fraction(len)`: -2=1/1, -1=1/2, 0=1/4 ... 5=1/128, other values taken as `1/len` ("whacky numbers 40, 28"). `setTuplet(tuple)`: 3->3:2, 5->5:4, 6->6:4, 7->7:4, 9..13 -> N:8 (unsupported asserts); `setupTupletStyle` shows the *ratio* for non-"real" tuplets (`:454-479`). Dynamics map `{ppp..fff}` (`addDynamic`, 9-entry table with index 0 = f). Spanner-like effects (palm mute, let ring, trill, rasgueado, vibrato, harmonic marks) are not created per note: each `addX(cr, hasX)` feeds `ContiniousElementsBuilder::buildContiniousElement`, which glues consecutive beats into one line (`importgtp.cpp:300-370`).
**GP5 `readBeat` (`importgtp-gp5.cpp:199-454`)** decodes `beatBits` (DOTTED/PAUSE/TUPLET/CHORD/LYRICS(=free text)/EFFECTS/MIX_CHANGE), duration (`len`, tuplet int), embedded chord diagram (skip 17, 21-char name, skip 4, `readChord`, skip 32), beat effects, mix change, **used-strings bitmask** (`strings`; `strings==0` => rest; voice != 0 with `pause==0 && strings==0` => no element), then one `readNote(6-i, note)` per set bit. Notes with fret `-20` are deleted (and an emptied chord removed). Let-ring flag is remembered per chord (`m_letRingForChords`, "fixing gp5 bug with not storing let ring for tied notes"). Beat-effect words are decoded base-100 digit by digit (`applyBeatEffects(chord, effects % 100)` loop). Dotted rest or `l >= measure length` => `V_MEASURE` rest. `GuitarPro5::read` (`:877-`): info, lyrics, page setup, tempo (+1 skip if version > 500), key, channels (64 x 12), 19 articulations/RSE words, `measures`, `staves`, then per-bar header bits (`SCORE_TIMESIG_*`, `REPEAT_START/END(+count)`, `MARKER`, `VOLTA` (bit-flag list -> `voltaInfo`, `repeats=n+1`), `KEYSIG` (1..7 sharps, 255..249 flats via `-256+k`), `DOUBLE_BAR`), then one Part+Staff per track, `createMeasures`, `readTracks`, `readMeasures`, tuning pass using `stringDatas` (GP tunings per part id).
**Bends (GP1-5)**: `readBendDataFromFile` = icon byte, amplitude int, N points of (time int, pitch int, vibrato byte) -> `PitchValue(time,pitch,vibrato)`; `createBend` drops curves with `<2` points or **max pitch 0 ("not adding hold on 0 pitch")** and hands the rest to `GuitarBendImporter::collectBend` (`importgtp.cpp:615-649`).

**GP6 (`.gpx`, `importgtp-gp6.cpp:244-483`).** `readGPX` is **recursive**: first int = header; `BCFZ` (compressed) -> bit-level LZ decompression (flag bit; `1` = back-reference: 4-bit width `bits`, `offs`,`size` read LSB-first via `readBitsReversed`, copy `min(size,offs)` bytes from `size()-offs`; `0` = literal run: 2-bit length LSB-first then that many 8-bit bytes) into a BCFS buffer which is fed back into `readGPX`; `BCFS` (uncompressed) = 4096-byte sectors, a sector whose first int is `2` is a file entry (name at +4 up to 127 chars, size at +0x8C, block list from +0x94); only the file named `score.gpif` is parsed (`parseFile`). GP7+ (`.gp`) is a ZIP with `Content/score.gpif` read the same way. Both feed `GP6DomBuilder`/`GP7DomBuilder` -> `GPDomModel` -> `GPConverter(...).convertGP()` (`readGpif`, `:372-383`).

**`GPConverter::convertGP` (`gtp\gpconverter.cpp:262-274`)** runs: `setUpGPScore` (metadata/page), `setUpTracks` (parts/staves/instruments/tuning/drumset), `collectTempoMap`, `convert(masterBars)`, `clearDefectedSpanner`, `fixPercussion` (single-drum parts: program reset to 0/bank 128), `addCapos`, `utils::addPlayCountTexts`. `convert()` per master bar -> `convertMasterBar` (`:356-371`): `addMeasure`, `addTimeSig`, `addKeySig`, `addBarline`, `addRepeat`, `collectFermatas`, `convertBars` (per track `curTrack += VOICES`: `addClef`, `addSimileMark` (short-circuits the bar), `convertVoices`, `hideRestsInEmptyMeasures`), `addTripletFeel`, `addSection` (rehearsal/section text), `addDirection` (jumps/markers), then `fixEmptyMeasures` (an all-rest staff keeps one `V_MEASURE` rest so layout can build mm-rests). After all bars: continuous-element builder flush, `addTempoMap`, `addInstrumentChanges`, **`m_guitarBendImporter->addElementsToScore()`** (bends are deferred until all chords exist), `addFermatas`, `addContinuousSlideHammerOn`, `addTuning`.
`convertBeat` (`:555-658`): beat tick = running `ctx.curTick`; creates the ChordRest (`addChordRest`), grace beats are queued in `graceChords` and attached (before-style `APPOGGIATURA` for on-beat, else `ACCIACCATURA`; size 1/8, or 1/16 when several) to the next real chord; `setBeamMode`; then `convertNotes` (each note: `setPitch`, `setTpc`, harmonics, bend, let-ring/palm-mute, ghost/dead, accent, slide, pick-scrape, hammer-on/pull-off collection, tapping, string number, ornament, vibrato, trill, fingering, ties) and ~25 per-beat decorations in a fixed order (tuplet, timer, free text, fade, hairpin, tremolo, pick stroke, dynamic, wah, golpe, fret diagram/barre, tapping, slapped, popped, brush, arpeggio, lyrics, legato; then spanner-ish: ottava, let ring, palm mute, trill, rasgueado, dive, pick scrape, harmonic marks, vibrato).
`setPitch` (`:2094-2156`): GP string numbering is inverted (`msString = strings-1-gpString`); pitch priority: explicit `midi` > `octave*12+tone` > drum `(element,variation)` > percussion-channel program > `stringData->getPitch(string, fret+capo)` + transpose; clamped 0..127; without a string, `getStringNumberFor` picks one and recomputes fret; non-experimental drum staves remap through `_drumExtension`.
**Tempo map (`addTempoMap`, `:1459-1536`)**: per measure, per automation: `tempoUnit` 0 = value as-is, 5 = `v + 2v`, else `v*unit/2` (-> quarter bpm); position is a fraction of the measure; text `<sym>metNoteQuarterUp</sym> = N` (prefixed by label); `linear` automations open a `GradualTempoChange` closed at the next tempo, typed accel. if the new tempo is higher else rall.

**Bend importer pipeline (`guitarbendimport\`).** `GuitarBendImporter` holds a `BendDataCollector` (`m_bendCollector`), `DiveDataCollector`, and `BendBuilder`. GP7+ curves arrive via `gpBendCurveToPitchValues` (`gpconverter.cpp:2011-`): time scaled `gpTime*MAX_TIME/100`, GPX `-1` offsets normalized to 0, optional middle points (`middleOffset1/2`, dropped if >= destination or duplicate of the last point). `BendInfoConverter::fillBendInfo` (`bendinfoconverter.cpp:29-138`) converts a pitch curve into `ImportedBendInfo{type, segments[], timeOffsetFromStart, pitchOffsetFromStart}`: each adjacent pair is classified (`SAME_PITCH_*`, `INCREASED/DECREASED_PITCH_*`); same-direction runs are merged into one segment (no "hold"); leading flat/jump at the start = **prebend** (`PREBEND` if start pitch > 0); a trailing flat extends `middleTime`; last segment `endTime = MAX_TIME`; one segment of exactly one quarter-tone (`GP_PITCH_PER_QUARTERTONE`) = `SLIGHT_BEND`. `BendBuilder::addElementsToScore` (`bendbuilder.cpp:53-67`) then, in this order: `createPreBends` (transposes note up 1 diatonic step so `addGuitarBend(PRE_BEND)` creates the grace and pitches it back, sets start/end time factors and `endNotePitch(+quarter-tone off)`, tidies ties), `createSlightBends`, `createGraceAfterNotes(BEND)`, `createTiedSpans(BEND)`, `createPreDives`, dive tied spans / grace-after, and finally `BendDataProcessorSplitChord` (`splitchord\*`) which splits a chord's duration to host multi-segment bends (⭐ **dead in the shipped build** — it runs only when `bendCtx.splitChordCtx` is non-null, which needs `-DSPLIT_CHORD_DURATIONS`; that macro is defined nowhere in the tree, so `BendDataCollector` takes its `#else` path; see §8.10 round-4). Dive (tremolo-bar) data take the parallel `DiveDataCollector`/`diveinfoconverter` path.

### 8.6 Long-tail formats (record-level facts; partly outline)

- **Capella `.cap` (`capella\internal\capella.cpp`, 2.9k lines; TRACED structure, not every object)**: stream of variable-length integers — `readUnsigned` (`<254` byte, `254`+u16, `255`+u32), `readInt` (signed byte, `-128`+s16, `127`+s32) — and signature chars. Hierarchy: `Capella::read(QFile*)` -> layout (`readLayout`, `readStaveLayout`) -> systems `'S'` (`readSystem`: bar-count, beam mode, tempo, flags: justified/page-break/instrument-notation) -> staves `'V'` (`readStaff`: numerator, `log2Denom=(d&0x7f)-1`, alla-breve bit 0x80; illegal fractions reset to 4/4) -> voices `'C'` (`readVoice`: lyrics y/font, stem dir) -> note objects by type byte: REST, CHORD (and PAGE_BKGR parsed as chord), CLEF, KEY, METER, EXPL_BARLINE (others `ASSERT_X` "bad voice type"; non-chord objects carry a color first, chord/rest use compressed color). Draw objects (slurs, text, lines, brackets, volta, trill, wedge, guitar, notelines...) via `readDrawObjectArray`. Wrong signatures throw `Capella::Error::BAD_*_SIG`; `verifyLength` guards string reads against EOF. `convertCapella` maps to DOM. `capx` (XML in ZIP) has a parallel `capxml.cpp` reader.
- **BB (`bb\internal\bb.cpp`, outline + quantizer)**: `BBFile::read` -> tracks of MIDI-like events. `BBTrack::cleanup` quantizes bar by bar (`quantize`): per bar the **raster = smallest note duration in the bar rounded up to a power-of-2 fraction of DIVISION** (min DIVISION/16, capped at DIVISION when > a quarter), onsets rounded to nearest raster (`(on + raster/2)/raster*raster`, "prefer moving note to the right"), durations snapped to the next onset when within one raster else `quantizeLen`; then same-pitch overlaps truncated. `findChords`: notes whose on/off times differ by <= 3 ticks (`jitter`) merge into one chord (drum tracks: also same drumset voice). **`separateVoices` is a stub that returns 1** (`bb.cpp:1169-1172`): BB import is single-voice.
- **BWW (`bww\internal\bww\lexer.cpp`)**: line-based; header lines (`Bagpipe Reader`, `MIDINoteMappings`, `FrequencyMappings`, `InstrumentMappings`, `GracenoteDurations`, `FontSizes`, `TuneFormat`) become COMMENT (ignored), `TuneTempo` -> TEMPO, quoted lines -> STRING, otherwise whitespace-split words each classified by regex: clef `&`, key `sharp[cf]`, time `\d+_(1|2|4|8|16|32)`, part markers (`I!`, `''!I`, `'intro`, digits 2-9, ...), bars (`!`, `!t`, `!!t`), note `(LG|LA|[B-F]|HG|HA)[lr]?_(1|2|4|8|16|32)`, tie `^t[es]`, triplet `^3[es]`, dot `'x`, else gracenote map lookup or UNKNOWN. `Bww::Parser` consumes the symbols and drives `MsScWriter`.
- **MuseData (`musedata\internal\musedata.cpp`, TRACED readNote head)**: fixed-column record lines. `readNote`: col 0 = step letter (A-G, table `{9,11,0,2,4,5,7}` since A=9), cols 1-2 = `#`/`f`/octave digit, cols 5-7 = duration in `_division` units -> ticks `(d*DIVISION + div/2)/div`, col 19-21 = tuplet `a:b` (only 3:2 supported, others logged), col 22 stem u/d, col 23 staff digit, cols 31-41 notations: `(`/`)` slur 0, `[`/`]` slur 1 ...
